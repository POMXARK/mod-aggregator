# Инструкция по добавлению скриншотов

## Где хранить скриншоты

Все скриншоты должны находиться в папке:
```
website/static/img/screenshots/
```

## Именование файлов

Используйте понятные имена файлов на английском языке:
- `add-file-button.png` - кнопка добавления файла
- `file-list.png` - список файлов
- `dependency-check.png` - проверка зависимостей
- `create-collection.png` - создание коллекции

## Формат и размер

- **Формат**: PNG (для скриншотов с текстом) или JPG (для фотографий)
- **Размер**: Рекомендуется не более 1MB на изображение
- **Разрешение**: Достаточно 1920x1080 или меньше

## Как сделать скриншот

### Windows
1. Нажмите `Win + Shift + S` для инструмента "Ножницы"
2. Выберите область экрана
3. Сохраните изображение в `website/static/img/screenshots/`

### macOS
1. Нажмите `Cmd + Shift + 4`
2. Выберите область экрана
3. Сохраните изображение в `website/static/img/screenshots/`

### Linux
1. Используйте инструмент скриншотов вашего дистрибутива
2. Или установите `gnome-screenshot` или `scrot`
3. Сохраните изображение в `website/static/img/screenshots/`

## Использование в документации

В документации используйте относительный путь:

```markdown
![Описание изображения](./screenshots/filename.png)
```

Пример:
```markdown
![Добавление файла через форму](./screenshots/add-file-button.png)
```

## Обработка скриншотов

Перед добавлением скриншота:
1. Убедитесь, что на скриншоте нет личной информации
2. Обрежьте лишние области
3. Убедитесь, что текст читаем
4. Оптимизируйте размер файла (можно использовать [TinyPNG](https://tinypng.com/))

## Требования к скриншотам

- **Актуальность**: Скриншоты должны соответствовать текущей версии приложения
- **Читаемость**: Текст должен быть четким и читаемым
- **Релевантность**: Скриншот должен иллюстрировать описываемую функцию
- **Консистентность**: Используйте одинаковый стиль для всех скриншотов
