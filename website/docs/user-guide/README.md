## Скриншоты

Все скриншоты находятся в папке `screenshots/` относительно каждого документа.

Для добавления новых скриншотов:
1. Сделайте скриншот интерфейса
2. Сохраните его в `website/static/img/screenshots/`
3. Используйте относительный путь в документации: `![Описание](./screenshots/filename.png)`

## Обновление документации

Документация обновляется вместе с приложением. Если вы нашли ошибку или хотите добавить информацию:
1. Создайте issue в репозитории
2. Или создайте pull request с исправлениями
