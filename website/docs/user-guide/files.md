# Работа с файлами

Эта страница описывает, как работать с файлами в Mod Aggregator.

## Добавление файлов

### Способ 1: Через кнопку "Добавить файл"

1. Откройте страницу **"Файлы"** в боковом меню
2. Нажмите кнопку **"Добавить файл"** в правом верхнем углу
3. Заполните форму:
   - **Название** (обязательно) - имя файла/мода
   - **Версия** (обязательно) - версия файла (например, `1.0.0`)
   - **Путь** (опционально) - путь к файлу на диске
   - **Метаданные** (опционально) - дополнительная информация в формате JSON
4. Нажмите **"Сохранить"**

![Добавление файла через форму](./screenshots/add-file-button.png)

### Способ 2: Импорт из модов

1. Откройте страницу **"Моды"**
2. Найдите нужный мод
3. Нажмите кнопку **"Импортировать в файлы"** (если доступна)
4. Мод будет преобразован в файл с сохранением всех метаданных

## Просмотр файлов

На странице **"Файлы"** отображается список всех файлов в системе:

- **Имя файла** - в формате `название@версия` (например, `my-mod@1.0.0`)
- **Путь** - путь к файлу на диске (если указан)
- **Дата создания** - когда файл был добавлен в систему

![Список файлов](./screenshots/file-list.png)

## Выбор файлов

### Одиночный выбор
- Кликните по файлу для выбора

### Множественный выбор
- **Ctrl/Cmd + Click** - добавить/убрать файл из выбора
- **Shift + Click** - выбрать диапазон файлов
- **"Выбрать все"** - выбрать все файлы на странице

### Отображение выбранных
В заголовке страницы отображается количество выбранных файлов:
```
5 файлов (3 выбрано)
```

## Редактирование файла

1. Кликните дважды по файлу или используйте контекстное меню
2. Откроется форма редактирования
3. Измените нужные поля
4. Нажмите **"Сохранить"**

## Удаление файлов

### Удаление одного файла
1. Выберите файл
2. Нажмите кнопку **"Удалить"** в контекстном меню или используйте клавишу **Delete**

### Пакетное удаление
1. Выберите несколько файлов (см. раздел "Выбор файлов")
2. Нажмите кнопку **"Пакетные операции"** в заголовке
3. Выберите **"Удалить выбранные"**
4. Подтвердите удаление

:::warning Внимание
При удалении файла, который используется другими файлами как зависимость, система предупредит вас и покажет список зависимых файлов.
:::

## Управление зависимостями

Файлы могут зависеть от других файлов (как пакеты в npm).

### Добавление зависимости

1. Откройте файл для редактирования
2. Перейдите в раздел **"Зависимости"**
3. Нажмите **"Добавить зависимость"**
4. Укажите:
   - **Имя файла** - название файла-зависимости
   - **Версия** (опционально) - конкретная версия или любая
   - **Тип зависимости**:
     - **required** - обязательная (файл не может работать без неё)
     - **optional** - опциональная (файл может работать без неё)
     - **peer** - зависимость на уровне (как в npm peer dependencies)
5. Нажмите **"Добавить"**

### Проверка зависимостей

1. Выберите файл(ы)
2. Нажмите **"Проверить зависимости"** в меню пакетных операций
3. Система покажет:
   - Отсутствующие зависимости
   - Конфликты версий
   - Удовлетворенные зависимости

![Проверка зависимостей](./screenshots/dependency-check.png)

### Визуализация зависимостей

1. Откройте файл
2. Нажмите **"Показать граф зависимостей"**
3. Откроется визуальный граф всех зависимостей файла

## Импорт и экспорт

### Экспорт файла

1. Выберите файл
2. Нажмите **"Экспортировать"** в контекстном меню
3. Файл будет экспортирован в JSON формате
4. Сохраните файл в нужное место

### Импорт файла

1. Нажмите **"Импорт"** в заголовке страницы
2. Выберите JSON файл для импорта
3. Система проверит файл и покажет предварительный просмотр
4. Нажмите **"Импортировать"**

:::info Формат импорта
Файлы экспортируются и импортируются в JSON формате, который включает:
- Информацию о файле (название, версия, путь, метаданные)
- Все зависимости файла
- Настройки и конфигурацию
:::

## Переупорядочивание файлов

Вы можете изменить порядок отображения файлов:

1. Зажмите файл левой кнопкой мыши
2. Перетащите его в нужное место
3. Отпустите кнопку мыши

Порядок файлов сохраняется при следующем открытии приложения.
