# Начало работы

Добро пожаловать в Mod Aggregator! Это руководство поможет вам быстро начать работу с приложением.

## Первый запуск

### Запуск приложения

1. Запустите приложение Mod Aggregator
2. При первом запуске вы увидите главную страницу с боковым меню

![Главный экран](./screenshots/main-screen.png)

### Навигация

Боковое меню содержит следующие разделы:

- **Моды** - список модов, полученных с сайтов
- **Сайты** - управление сайтами для парсинга
- **Конструктор** - визуальный конструктор парсеров
- **Уведомления** - уведомления о новых версиях модов
- **Файлы** - управление файлами и зависимостями
- **Коллекции** - управление коллекциями файлов

![Боковое меню](./screenshots/sidebar.png)

## Быстрый старт

### Шаг 1: Добавление первого файла

1. Откройте раздел **"Файлы"**
2. Нажмите кнопку **"Добавить файл"**
3. Заполните форму:
   - Название: `my-first-mod`
   - Версия: `1.0.0`
4. Нажмите **"Сохранить"**

![Добавление первого файла](./screenshots/add-first-file.png)

### Шаг 2: Создание коллекции

1. Откройте раздел **"Коллекции"**
2. Нажмите **"Создать коллекцию"**
3. Укажите название и описание
4. Добавьте файлы в коллекцию

![Создание коллекции](./screenshots/create-collection.png)

### Шаг 3: Настройка зависимостей

1. Откройте файл для редактирования
2. Перейдите в раздел **"Зависимости"**
3. Добавьте зависимости от других файлов

![Настройка зависимостей](./screenshots/add-dependencies.png)

## Основные концепции

### Файлы и моды

В системе Mod Aggregator:
- **Моды** - это файлы, полученные автоматически через парсинг сайтов
- **Файлы** - это моды, добавленные вручную или импортированные

Моды и файлы - это одна и та же сущность, но с разными источниками данных.

### Идентификация файлов

Файлы идентифицируются комбинацией **название@версия** (например, `my-mod@1.0.0`), аналогично npm пакетам.

Это позволяет:
- Хранить несколько версий одного файла одновременно
- Точное указание версий в зависимостях
- Разрешение конфликтов версий

### Зависимости

Файлы могут зависеть от других файлов. Типы зависимостей:
- **required** - обязательная зависимость
- **optional** - опциональная зависимость
- **peer** - зависимость на уровне (как в npm peer dependencies)

### Коллекции

Коллекции - это группы файлов с опциональной логикой включения/выключения. Коллекции можно:
- Комбинировать друг с другом
- Настраивать условия включения файлов
- Экспортировать и импортировать
