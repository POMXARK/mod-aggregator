# Введение

Добро пожаловать в документацию **Mod Aggregator**!

Mod Aggregator - это десктопное приложение для агрегации модов из различных сайтов с визуальным конструктором парсеров. Аналог ModOrganizer/NexusMods с расширенными возможностями.

## Что это?

Mod Aggregator позволяет:

- 📦 **Агрегировать моды** из различных сайтов в одном месте
- 🎨 **Создавать парсеры** визуально через конструктор с нодами
- 🔄 **Отслеживать обновления** модов автоматически
- 💾 **Кэшировать страницы** для быстрого доступа
- 🔔 **Получать уведомления** о новых версиях модов

## Технологический стек

### Frontend
- **Svelte 5** - современный фреймворк с компиляцией во время сборки
- **TypeScript** - типизация для безопасности кода
- **Tailwind CSS** - утилитарные стили
- **@xyflow/svelte** - визуальный редактор графов

### Backend
- **Rust** - системный язык для производительности и безопасности
- **Tauri 2.0** - фреймворк для десктопных приложений
- **SQLite** - встроенная база данных
- **scraper** - парсинг HTML
