# Обзор архитектуры

## Mod Aggregator

Десктопное приложение для агрегации модов из различных сайтов с визуальным конструктором парсеров.

## Общая архитектура

```
┌─────────────────────────────────────────────────────────┐
│                    Frontend (Svelte 5)                   │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  │
│  │  Components  │  │   Composable │  │    Stores    │  │
│  └──────────────┘  └──────────────┘  └──────────────┘  │
└───────────────────────┬─────────────────────────────────┘
                        │ Tauri Commands
┌───────────────────────┴─────────────────────────────────┐
│                 Backend (Rust + Tauri)                    │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  │
│  │   Parser     │  │  Database    │  │ Notifications│  │
│  └──────────────┘  └──────────────┘  └──────────────┘  │
└───────────────────────┬─────────────────────────────────┘
                        │
┌───────────────────────┴─────────────────────────────────┐
│                    SQLite Database                        │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐             │
│  │  Sites   │  │   Mods   │  │ Notifications│          │
│  └──────────┘  └──────────┘  └──────────┘             │
└──────────────────────────────────────────────────────────┘
```

## Технологический стек

### Frontend
- **Svelte 5** - современный фреймворк с компиляцией во время сборки
- **TypeScript** - типизация для безопасности кода
- **Tailwind CSS** - утилитарные стили
- **@xyflow/svelte** - визуальный редактор графов для конструктора парсеров

### Backend
- **Rust** - системный язык для производительности и безопасности
- **Tauri 2.0** - фреймворк для десктопных приложений
- **SQLite** - встроенная база данных
- **SQLx** - асинхронный SQL драйвер
- **scraper** - парсинг HTML
- **reqwest** - HTTP клиент

## Основные компоненты

### Frontend компоненты

1. **App.svelte** - главный компонент с роутингом
2. **ParserBuilder.svelte** - визуальный конструктор парсеров
3. **PageViewer.svelte** - просмотр HTML страниц
4. **SitesManager.svelte** - управление сайтами
5. **ModsList.svelte** - список модов
6. **NotificationsPanel.svelte** - панель уведомлений

### Backend модули

1. **main.rs** - Tauri команды и обработчики
2. **database.rs** - работа с SQLite
3. **parser.rs** - движок парсинга HTML
4. **parser_builder.rs** - построение парсеров из конфигурации
5. **models.rs** - модели данных
6. **notification.rs** - система уведомлений

## Потоки данных

### Загрузка и парсинг страницы

```
User Action → Frontend → Tauri Command → Parser → Database
                ↓              ↓            ↓         ↓
            UI Update    Cache Check   HTML Parse  Save Result
```

### Создание парсера

```
User Config → ParserBuilder → Validate → Build Parser → Save to DB
                ↓                ↓           ↓            ↓
            Visual Nodes    Selectors   Parser Code   Site Config
```

## Принципы архитектуры

1. **Разделение ответственности**
   - Frontend: UI и пользовательский опыт
   - Backend: бизнес-логика и работа с данными

2. **Модульность**
   - Компоненты изолированы и переиспользуемы
   - Модули имеют четкие интерфейсы

3. **Типобезопасность**
   - TypeScript на frontend
   - Rust на backend
   - Валидация данных на границах

4. **Производительность**
   - Кэширование страниц
   - Асинхронные операции
   - Минимизация перерисовок
