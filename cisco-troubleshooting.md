# Устранение неполадок Cisco AnyConnect в WSL

## 🔍 Проверка перед подключением

### 1. Твои данные
```bash
# Создай файл с настройками
./cisco-anyconnect-setup.sh vpn.company.com Employees john.doe@company.com

# Проверь что создался скрипт
ls -la connect-cisco.sh
```

### 2. SOCKS5 прокси работает
```bash
./test-vpn-bridge.sh
```

## 🚨 Распространенные проблемы

### "Не удается разрешить имя сервера"
```
Причина: DNS проблема
Решение: проверь доступность сервера из WSL
```
```bash
# Проверь DNS
nslookup vpn.company.com

# Или ping
ping vpn.company.com
```

### "Неверная группа аутентификации"
```
Причина: неправильное название группы
Решение: узнай точное название у IT
```
```bash
# Попробуй без группы сначала
./vpn-connect.sh openconnect vpn.company.com --user=john.doe --no-cert-check
```

### "Сертификат сервера не доверен"
```
Причина: самоподписанный сертификат
Решение: добавь --no-cert-check
```

### "Ошибка аутентификации"
```
Причина: неправильный логин/пароль
Решение: проверь учетные данные
```

## 🛠️ Диагностические команды

### Проверить статус WSL сети
```bash
ip addr show
ip route show
```

### Проверить доступность VPN сервера
```bash
curl -I https://vpn.company.com
openssl s_client -connect vpn.company.com:443 -servername vpn.company.com
```

### Проверить SOCKS5
```bash
# Из WSL
curl --socks5 localhost:1080 ifconfig.me

# Из Windows (в браузере)
# Настрой прокси 127.0.0.1:1080
```
