# Руководство по ручному тестированию адаптивности

## Способ 1: Использование скрипта в DevTools

1. Запустите приложение: `npm run tauri dev`
2. Откройте DevTools (F12 или Ctrl+Shift+I)
3. Перейдите на вкладку Console
4. Скопируйте содержимое файла `test-responsiveness.js`
5. Вставьте в консоль и нажмите Enter
6. Запустите функцию: `testResponsiveness()`
7. Скрипт автоматически изменит размер окна и выведет информацию о текущем состоянии

## Способ 2: Ручное изменение размера окна

### Тестовые размеры:

1. **Маленький экран (800x600)**
   - Проверьте: Sidebar должен быть компактным или скрытым
   - Иконки должны быть читаемыми
   - Текст не должен переполняться

2. **Средний экран (1024x768)**
   - Проверьте: Sidebar должен быть видимым
   - Grid должен показывать 2 колонки
   - Кнопки должны быть доступны

3. **HD экран (1280x720)**
   - Проверьте: Grid должен показывать 3 колонки
   - Все элементы должны быть хорошо видны

4. **Full HD экран (1920x1080)**
   - Проверьте: Grid должен показывать 4 колонки
   - Максимальная ширина контента должна быть ограничена

### Что проверять на каждом размере:

- [ ] Sidebar корректно адаптируется (ширина, иконки, текст)
- [ ] Иконки имеют правильный размер и не обрезаются
- [ ] Текст читаем и не переполняется
- [ ] Кнопки доступны и кликабельны
- [ ] Grid адаптируется под размер экрана (1-4 колонки)
- [ ] Модальные окна корректно отображаются
- [ ] Формы не выходят за границы экрана
- [ ] Скролл работает корректно

## Способ 3: Использование браузерных инструментов разработчика

1. Запустите приложение в браузере (если доступно)
2. Откройте DevTools (F12)
3. Используйте инструмент "Toggle device toolbar" (Ctrl+Shift+M)
4. Выберите различные размеры устройств
5. Проверьте адаптивность на каждом размере

## Способ 4: Автоматическое тестирование через Tauri API

Создайте команду в Rust для изменения размера окна:

```rust
#[tauri::command]
async fn set_window_size(width: f64, height: f64) -> Result<(), String> {
    use tauri::Manager;
    let window = tauri::Manager::get_webview_window(&app_handle, "main")
        .ok_or("Window not found")?;
    window.set_size(tauri::LogicalSize::new(width, height))?;
    Ok(())
}
```

Затем вызовите из консоли браузера:

```javascript
const { invoke } = await import('@tauri-apps/api/core');
await invoke('set_window_size', { width: 800, height: 600 });
```

## Рекомендации

- Тестируйте на реальных размерах экранов ваших пользователей
- Проверяйте как горизонтальную, так и вертикальную ориентацию
- Убедитесь, что все интерактивные элементы доступны
- Проверьте производительность на разных размерах
