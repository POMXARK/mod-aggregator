# Что нужно для запуска Cisco AnyConnect

## 🔑 Обязательные данные для Cisco AnyConnect

### 1. VPN Сервер
- **Адрес сервера**: URL твоей компании для Cisco AnyConnect
- **Примеры**: `vpn.company.com`, `ssl-vpn.company.com`, `secure.company.com`
- **Где найти**: в письме от IT или на корпоративном портале

### 2. Группа аутентификации (Connection Profile)
- **Название группы**: например `Employees`, `Remote Access`, `Full Access`
- **Важно**: это НЕ твой логин, а название профиля подключения
- **Где найти**: спроси у IT отдела или посмотри в существующем клиенте AnyConnect

### 3. Учетные данные
- **Имя пользователя**: твой корпоративный логин/email
- **Пароль**: корпоративный пароль (будет запрошен при подключении)

## 📝 Опциональные параметры

### Группа аутентификации
```
--authgroup=GROUP_NAME
```
Нужна если на сервере несколько групп пользователей.

### Сертификат сервера
```
--servercert pin-sha256:HASH_HERE
```
Для дополнительной безопасности. Можно получить из браузера при подключении к VPN.

### Прокси
```
--proxy=http://proxy.company.com:8080
```
Если VPN сервер доступен только через корпоративный прокси.

## 🚀 Примеры команд для Cisco AnyConnect

### Базовый вариант:
```bash
./vpn-connect.sh openconnect vpn.company.com --user=john.doe@company.com --authgroup=Employees
```

### С дополнительными опциями:
```bash
./vpn-connect.sh openconnect vpn.company.com \
  --user=john.doe@company.com \
  --authgroup=RemoteAccess \
  --no-cert-check
```

### Через специальный скрипт настройки:
```bash
./cisco-anyconnect-setup.sh vpn.company.com Employees john.doe@company.com
./connect-cisco.sh
```

## ❓ Как получить данные для Cisco AnyConnect

1. **Спроси у IT отдела компании**:
   - Адрес VPN сервера (обычно vpn.company.com)
   - **Название группы** (Connection Profile) - самое важное!
   - Твои учетные данные (логин/пароль)

2. **Из существующего клиента AnyConnect**:
   - Открой AnyConnect клиент в Windows
   - Посмотри в настройках какой сервер подключен
   - В выпадающем списке групп выбери нужную

3. **Из корпоративного портала**:
   - Зайди на портал самообслуживания
   - Найди раздел VPN/Remote Access
   - Там должны быть инструкции и данные для подключения

4. **Из браузера** (если есть веб-интерфейс):
   - Зайди на https://vpn.company.com
   - Посмотри доступные группы подключения

## 🆘 Если что-то не работает

- Попробуй `--no-cert-check` для обхода проверки сертификата
- Проверь логин/пароль
- Спроси у коллег - может быть специальная группа для WSL
- Попробуй подключиться из браузера сначала для проверки данных
