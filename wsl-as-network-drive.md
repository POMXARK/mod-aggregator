# 💿 Монтирование WSL как сетевой диск в Windows

## 🎯 СПОСОБ 1: Быстрое монтирование (BAT файл)

### Запуск:
```cmd
cd C:\Users\User\mod-aggregator
.\mount-wsl-as-drive.bat
```

**Результат:** Диск `W:` появится в проводнике

## 🎯 СПОСОБ 2: Гибкое монтирование (PowerShell)

### Запуск с параметрами:
```powershell
cd C:\Users\User\mod-aggregator
.\mount-wsl-drive.ps1 -DriveLetter "Z" -DistroName "Ubuntu"
```

### Параметры:
- `-DriveLetter "Z"` - буква диска (Z, Y, X, etc.)
- `-DistroName "Ubuntu"` - имя дистрибутива WSL

## 🎯 СПОСОБ 3: Ручное монтирование

### Через командную строку:
```cmd
# Проверить WSL
wsl -l -v

# Создать диск W:
net use W: "\\wsl$\Ubuntu" /persistent:yes
```

### Через PowerShell:
```powershell
# Создать диск Z:
New-PSDrive -Name "Z" -PSProvider FileSystem -Root "\\wsl$\Ubuntu" -Persist

# Проверить
Get-PSDrive
```

## 📁 ДОСТУП К ФАЙЛАМ

После монтирования:
- `W:\` - корень WSL Ubuntu
- `W:\home\roman\` - ваша домашняя папка
- `W:\mnt\c\Users\User\mod-aggregator\` - проект

## 🔧 УПРАВЛЕНИЕ ДИСКАМИ

### Просмотр подключенных дисков:
```cmd
net use
```

### Отключение диска:
```cmd
net use W: /delete
```

### Или в PowerShell:
```powershell
Remove-PSDrive -Name "W"
```

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### Производительность:
- Сетевой диск медленнее прямого доступа
- Лучше использовать для чтения, а не интенсивной разработки

### Ограничения:
- Нет поддержки некоторых операций с файлами
- Возможны проблемы с правами доступа
- Символические ссылки могут не работать

### Альтернативы:
- **Cursor + WSL extension** - лучший способ для разработки
- **UNC пути** - `\\wsl$\Ubuntu\path\to\file`
- **SSHFS** - монтирование через SSH

## 🔍 ДИАГНОСТИКА

### Если диск не создается:
```cmd
# Проверить WSL
wsl -l -v

# Проверить UNC доступ
dir \\wsl$\Ubuntu\
```

### Если буква диска занята:
```cmd
# Проверить занятые буквы
net use

# Использовать другую букву
net use Z: "\\wsl$\Ubuntu" /persistent:yes
```

## ✅ РЕКОМЕНДАЦИИ

1. **Используйте для чтения** файлов, не для активной разработки
2. **Выберите незанятую букву** диска (W, Z, Y, X)
3. **Делайте persistent** - диск сохранится после перезагрузки
4. **Для разработки** используйте Cursor + WSL extension

## 🎯 ГОТОВО!

Теперь WSL доступен как обычный диск в проводнике! 💿
