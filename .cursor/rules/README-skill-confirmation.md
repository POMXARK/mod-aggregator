# Правило подтверждения навыков (skill-confirmation)

## Назначение

Это правило добавляет уровень контроля над использованием навыков (skills) в Cursor IDE, аналогично тому, как работает Claude Code.

## Как это работает

### 1. Обнаружение навыка
Когда ваш запрос соответствует описанию навыка из `.claude/skills/`, система:

- Определяет подходящий навык
- Проверяет, требует ли он подтверждения
- Показывает диалог подтверждения

### 2. Диалог подтверждения
```
🎯 Обнаружен подходящий навык: [название]

📝 Описание: [краткое описание]

⚡ Действия: [что будет выполнено]

Применить навык? (y/n)
```

### 3. Выбор пользователя
- **y/yes** - применить навык полностью
- **n/no** - отклонить, продолжить без навыка

## Преимущества

### 🔒 Контроль
- Вы всегда знаете, когда применяется навык
- Можно предотвратить нежелательные действия
- Полный контроль над автоматизацией

### 📚 Прозрачность
- Видите название и описание навыка
- Понимаете, что будет выполнено
- Можете выбрать альтернативный подход

### 🛡️ Безопасность
- Предотвращает случайное выполнение скриптов
- Защищает от нежелательных изменений файлов
- Дает время на размышление

## Настройка

### В Cursor IDE:
1. **Settings → Rules**
2. Найти `skill-confirmation`
3. Режим: `ask` (запрашивать)
4. Сохранить

### Режимы работы:
- **ask** - запрашивать подтверждение (рекомендуется)
- **always** - всегда применять (автоматически)
- **never** - никогда не применять

## Доступные навыки

- `resize-handle-component` - Компоненты изменения размеров
- `state-persistence-svelte5-rust` - Сохранение состояния
- `static-analysis-frontend` - Статический анализ
- `static-analysis-frontend-warnings` - Управление предупреждениями
- `test-skill` - Тестовый навык
- `skill-creation-guide` - Руководство по созданию навыков

## Исключения

Некоторые навыки не требуют подтверждения:
- `skill-creation-guide` - информационный
- `test-skill` - для тестирования

## Примеры использования

### Пример 1: Создание компонента
```
Запрос: "Создай компонент Button"

Система: "🎯 Найден навык 'skill-creation-guide'
Это информационный навык по созданию компонентов.
Применить? (y/n)"

Пользователь: y
Результат: Применяется руководство по созданию компонентов
```

### Пример 2: Статический анализ
```
Запрос: "Проведи анализ кода"

Система: "🎯 Найден навык 'static-analysis-frontend'
Будет выполнен статический анализ с svelte-check.
Применить? (y/n)"

Пользователь: n
Результат: Продолжение без применения навыка
```

## Устранение неполадок

### Навык не обнаруживается
- Проверить, что файл находится в `.claude/skills/[name]/SKILL.md`
- Проверить синтаксис YAML frontmatter
- Проверить описание на ключевые слова

### Правило не работает
- Проверить включение в Settings → Rules
- Проверить режим правила (должен быть "ask")
- Перезапустить Cursor

### Неправильное поведение
- Проверить логи Cursor (F1 → Developer: Show Logs)
- Проверить конфликты с другими правилами

1. Обновить список в этом файле
2. Проверить описания навыков
3. Протестировать активацию и подтверждение
