# ParserRunner Components

Компоненты для запуска и управления парсером.

## Структура

```
parser-runner/
├── ParserRunnerControls.svelte  # Кнопки управления (запуск, остановка, очистка, настройки)
├── ParserSettingsPanel.svelte   # Панель настроек парсера
├── ParserProgress.svelte        # Индикатор прогресса
├── ParserError.svelte           # Отображение ошибок
├── ParserDiagnostics.svelte     # Диагностика выполнения
└── ParserResults.svelte         # Результаты парсинга
```

## Использование

Все компоненты используются внутри `ParserRunner.svelte`, который использует composables:
- `useParserSettings` - для управления настройками
- `useParserRunner` - для логики запуска парсера

## Компоненты

### ParserRunnerControls

Кнопки управления парсером:
- ▶️ Запустить парсер
- ⏹️ Остановить (показывается только во время выполнения)
- 🗑️ Очистить (показывается при наличии результатов/ошибок)
- ⚙️ Настройки (переключает видимость панели настроек)

### ParserSettingsPanel

Панель настроек парсера:
- Максимум элементов для обработки
- Таймаут выполнения (секунды)
- Медленный режим (чекбокс)
- Задержка между элементами (мс, показывается только в медленном режиме)
- Кнопка сброса настроек

### ParserProgress

Индикатор прогресса с анимацией. Показывается только во время выполнения парсера.

### ParserError

Отображение ошибок выполнения парсера. Показывается только если есть ошибка и парсер не выполняется.

### ParserDiagnostics

Список диагностических сообщений с цветовой индикацией:
- ℹ️ Информация (синий)
- ✅ Успех (зеленый)
- ⚠️ Предупреждение (желтый)
- ❌ Ошибка (красный)

### ParserResults

Отображение результатов парсинга:
- Список результатов с возможностью разворачивания/сворачивания
- Для каждого результата показываются все поля
- Длинные значения обрезаются с возможностью развернуть
- JSON значения можно форматировать
- Показывается детальная диагностика извлечения для каждого элемента

## Composables

### useParserSettings

Управление настройками парсера с синхронизацией между компонентами.

### useParserRunner

Логика запуска парсера:
- Получение HTML страницы
- Преобразование узлов и связей в формат для Tauri
- Запуск парсера с настройками
- Обработка результатов и ошибок
- Возможность остановки через AbortController
