# Конституция проекта Mod Aggregator

Этот документ определяет основные принципы и правила разработки проекта Mod Aggregator.

## Технический стек

### Frontend
- **Фреймворк**: Svelte 5 с TypeScript
- **Стилизация**: Tailwind CSS + кастомные стили
- **Граф нод**: @xyflow/svelte для визуального конструктора парсеров
- **Состояние**: Svelte 5 runes ($state, $derived, $effect)

### Backend
- **Фреймворк**: Tauri 2.0 для десктопных приложений
- **База данных**: SQLite через SQLx
- **Парсинг**: scraper crate для HTML парсинга
- **HTTP**: reqwest для запросов

## Принципы разработки

### Код
- Все комментарии пишутся на русском языке
- Каждая функция должна иметь JSDoc комментарий (для TypeScript) или документацию (для Rust)
- Следуй принципам компонентного подхода
- Обеспечивай типизацию через TypeScript и Rust
- Изолируй стили в компонентах

### Тестирование
- Используй Test-Driven Development (TDD) где это возможно
- Покрывай критическую логику тестами
- Frontend тесты: Vitest + Testing Library
- Backend тесты: стандартные Rust тесты

### Архитектура
- Разделение на Frontend (Svelte) и Backend (Rust/Tauri)
- Компоненты должны быть переиспользуемыми
- Используй composables для переиспользуемой логики
- Модели данных должны быть согласованы между Frontend и Backend

### Git и документация
- Коммиты должны быть осмысленными и структурированными
- README файлы в каждой директории описывают архитектуру компонентов
- Документация в формате Docusaurus находится в `website/docs/`

## Структура проекта

```
mod-aggregator/
├── src/                    # Frontend код (Svelte 5)
│   ├── components/         # Svelte компоненты
│   ├── lib/                # Утилиты и composables
│   └── App.svelte          # Главный компонент
├── src-tauri/              # Backend код (Rust)
│   └── src/
│       ├── main.rs         # Tauri команды
│       ├── database.rs     # Работа с БД
│       ├── parser.rs       # Движок парсинга
│       └── models.rs       # Модели данных
├── specs/                  # Спецификации для новых фич
├── memory/                 # Конституция и контекст проекта
└── .cursor/rules/          # Правила для Cursor AI
```
