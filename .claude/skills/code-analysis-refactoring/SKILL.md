# Анализ кода и рефакторинга

## Обзор

Этот навык предоставляет комплексный анализ размера кода в проекте с выявлением кандидатов на рефакторинг. Автоматически анализирует файлы, подсчитывает строки кода и генерирует рекомендации по улучшению структуры проекта.

## Когда использовать

- Оценка технического долга проекта
- Планирование рефакторинга
- Мониторинг качества кода
- Поиск крупных файлов для оптимизации
- Анализ распределения кода по языкам

## Инструкции

### Шаг 1: Проверка наличия скриптов анализа



### Шаг 3: Запуск быстрого анализа


### Шаг 4: Детальный анализ с отчетом


## Структура скриптов

### scripts/update-code-stats.js
Основной скрипт для полного анализа:
- Подсчет строк кода во всех файлах
- Категоризация по размеру (>2000, 1000-2000, 500-1000, 200-500 строк)
- Генерация детального отчета REFACTORING-ANALYSIS.md
- Обновление раздела статистики в README.md

### scripts/quick-refactor-check.js
Быстрый анализ для ежедневного использования:
- Показ только критических и высокоприоритетных файлов
- Минимальный вывод для быстрого обзора

## Категории рефакторинга

### 🚨 Критические кандидаты (>2000 строк)
**Срочные действия:**
- Разбить на несколько модулей/компонентов
- Вынести общую логику в отдельные функции
- Рассмотреть паттерн "Extract Class" или "Extract Module"

### ⚠️ Высокий приоритет (1000-2000 строк)
**Рекомендуется в ближайшее время:**
- Вынести части логики в отдельные функции
- Рассмотреть разделение на подкомпоненты
- Проверить на наличие дублированного кода

### 📋 Средний приоритет (500-1000 строк)
**Рассмотреть при модификации:**
- Мониторить рост файла
- Рассмотреть извлечение утилитарных функций
- Проверить single responsibility principle

## Примеры использования

### Пример 1: Еженедельный анализ проекта

```bash
# Запрос пользователя

# Действия навыка
1. npm run analyze-refactoring
2. Показать краткую сводку результатов
3. Открыть REFACTORING-ANALYSIS.md для детального изучения
4. Обновить README.md со свежей статистикой
```

### Пример 2: Быстрая проверка перед коммитом

```bash
# Запрос пользователя
"Проверь нет ли слишком больших файлов перед коммитом"

# Действия навыка
1. npm run check-refactoring
2. Показать только файлы >1000 строк
3. Дать рекомендации по разбивке если нужно
```

### Пример 3: Мониторинг роста файлов

```bash
# Запрос пользователя

# Действия навыка
1. npm run update-code-stats
2. Сравнить с предыдущими результатами
3. Выделить файлы с ростом >20%
```

## Автоматизация

### Git hooks для автоматического анализа

```bash
# В .git/hooks/pre-commit
#!/bin/bash
echo "🔍 Анализ кода перед коммитом..."
npm run check-refactoring

# Спросить пользователя о продолжении
read -p "Продолжить коммит? (y/n): " confirm
if [[ $confirm != "y" ]]; then
  echo "Коммит отменен"
  exit 1
fi
```

### CI/CD интеграция

```yaml
# В .github/workflows/code-analysis.yml
name: Code Analysis
on: [push, pull_request]

jobs:
  analyze:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: '18'
      - run: npm install
      - run: npm run analyze-refactoring
      - uses: actions/upload-artifact@v3
        with:
          name: refactoring-report
          path: REFACTORING-ANALYSIS.md
```

## Интерпретация результатов

### Метрики качества

- **Критических файлов**: < 1% от общего числа
- **Высокий приоритет**: < 5% от общего числа
- **Средний приоритет**: < 15% от общего числа

### Признаки проблем

1. **Много критических файлов** → Срочный рефакторинг нужен
2. **Большой разброс размеров** → Несогласованная архитектура
3. **Рост крупных файлов** → Недостаточная декомпозиция

## Устранение неполадок

### Проблема: Скрипт не находит файлы

```bash
# Проверить расширения файлов
find src -name "*.ts" -o -name "*.js" | head -5

# Проверить права доступа
ls -la scripts/
```

### Проблема: Неправильные результаты подсчета

```bash
# Проверить конкретный файл
wc -l src/components/LargeComponent.svelte

# Сравнить с результатом скрипта
node -e "console.log(require('fs').readFileSync('src/components/LargeComponent.svelte', 'utf8').split('\n').length)"
```

### Проблема: Скрипт падает с ошибкой

```bash
# Запустить с отладкой
node --trace-warnings scripts/update-code-stats.js

# Проверить синтаксис
node -c scripts/update-code-stats.js
```
