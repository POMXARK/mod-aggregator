# Руководство по созданию навыков Claude Code

## Обзор

Этот навык содержит полное руководство по созданию и управлению навыками Claude Code. Следуйте инструкциям для создания эффективных и правильно структурированных навыков.

## Структура навыка

### 1. Создание директории навыка

```bash
# Создать директорию для нового навыка
mkdir .claude/skills/your-skill-name

# Перейти в директорию
cd .claude/skills/your-skill-name
```

### 2. Создание SKILL.md файла

Каждый навык должен иметь файл `SKILL.md` в своей директории.

**Обязательная структура:**

```markdown
---
name: your-skill-name
description: Краткое описание когда использовать этот навык. Включите ключевые слова для активации.
version: 1.0.0
---

# Название навыка

## Описание и инструкции

Подробные инструкции по использованию навыка...
```

## Формат YAML frontmatter

### Обязательные поля:

```yaml
---
name: skill-name-kebab-case
description: Подробное описание когда и как использовать навык. Включите trigger words.
version: 1.0.0
---
```

### Дополнительные поля:

```yaml
---
name: advanced-skill
description: Расширенный навык для сложных задач
version: 2.1.0
allowed-tools: Read, Grep, Bash(python:*)  # Ограничение инструментов
author: Your Name                         # Автор навыка
tags: [development, testing, advanced]   # Теги для категоризации
---
```

## Лучшие практики описаний

### ✅ Правильные описания:

```
description: Создание и управление API эндпоинтами в Express.js приложениях. Использовать при разработке REST API, добавлении новых роутов или модификации существующих эндпоинтов.
```

```
description: Оптимизация производительности React компонентов. Использовать при профилировании, устранении bottle-necks или улучшении рендеринга.
```

### ❌ Неправильные описания:

```
description: Помощь с кодом
```

```
description: Разные задачи
```

**Почему правильные описания важны:**
- Claude Code использует семантический анализ для активации навыков
- Ключевые слова помогают точному matching
- Описание должно отвечать на вопросы "что" и "когда"

## Ограничение инструментов

### Поле allowed-tools:

```yaml
allowed-tools: Read, Grep, Bash(node:*,python:*)
```

**Доступные инструменты:**
- `Read` - чтение файлов
- `Grep` - поиск в файлах
- `Bash(command)` - выполнение bash команд
- `Edit` - редактирование файлов
- `Run` - запуск скриптов

**Примеры:**
```yaml
# Только чтение (безопасный навык)
allowed-tools: Read, Grep

# С ограниченными командами
allowed-tools: Bash(git:*,npm:*)

# Полный доступ
# allowed-tools: не указывать
```

## Тестирование навыков

### 1. Проверка синтаксиса

```bash
# Проверить YAML frontmatter
head -10 .claude/skills/your-skill/SKILL.md

# Проверить структуру
ls -la .claude/skills/your-skill/
```

### 2. Тестирование в Claude Code

```bash
# Запустить Claude Code
npx claude

# Проверить загрузку навыков
What Skills are available?

# Тестировать активацию
[Ваш тестовый запрос]
```

### 3. Проверка активации

Убедитесь, что навык активируется при:
- Точных ключевых словах из описания
- Семантически похожих запросах
- Не активируется при неподходящих запросах

## Отладка навыков

### Распространенные проблемы:

1. **Навык не загружается**
   - Проверьте синтаксис YAML
   - Убедитесь в правильной структуре директорий
   - Перезапустите Claude Code

2. **Навык не активируется**
   - Проверьте описание на ключевые слова
   - Попробуйте другие формулировки запросов
   - Убедитесь, что навык в `.claude/skills/`

3. **Ошибки в выполнении**
   - Проверьте allowed-tools
   - Убедитесь в доступности команд/файлов
   - Проверьте логи Claude Code

### Логирование:

```bash
# Включить debug режим
npx claude --debug

# Посмотреть логи загрузки навыков
npx claude --debug 2>&1 | grep skill
```
