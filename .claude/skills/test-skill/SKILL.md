# Тестовый навык

Этот навык предназначен для проверки работы системы навыков Claude Code.

## Инструкции по тестированию

1. Запустите Python скрипт для проверки работы команд:

```bash
python -c "print('hello world')"
```

2. Или используйте предоставленный тестовый скрипт:

```bash
python test.py
```

3. Убедитесь, что выводится "hello world"

4. Это подтверждает, что навык успешно активирован и может выполнять команды
