# План реализации гибридной архитектуры

## 🎯 **Цель проекта**
Реализовать гибридный подход к архитектуре приложения: простая структура + path mapping + конфигурация компонентов, без сложной Porto/DI системы.

## ✅ **Выполненные задачи**

### 1. **Установка зависимостей (✅ Завершено)**
- Установлены все npm зависимости командой `npm install`
- Установлен Tauri CLI глобально (`npm install -g @tauri-apps/cli`)

### 2. **Упрощение path mapping (✅ Завершено)**
- Обновлен `tsconfig.json` с минимальным набором алиасов:
  - `@/*` → `./src/*`
  - `@/lib/*` → `./src/lib/*`
  - `@/components/*` → `./src/components/*`
  - `@/types/*` → `./src/types/*`
  - `@/config/*` → `./src/config/*`

### 3. **Система конфигурации компонентов (✅ Завершено)**
- Создан файл `src/config/components.ts` с:

- Обновлен `App.svelte` для использования конфигурации
- Обновлен `Sidebar.svelte` для отображения только включенных компонентов

### 4. **UI для управления компонентами (✅ Завершено)**

  - Кнопками экспорта/импорта настроек
  - Кнопкой сброса к настройкам по умолчанию
- Добавлена страница "settings" в приложение
- Добавлена кнопка "Настройки" в боковое меню

### 5. **Обновление импортов (✅ Завершено)**
- Основные компоненты обновлены на path mapping (`@/lib/tauri-wrapper`, `@/types/*`, `@/components/*`)

- Упрощены импорты иконок - теперь используются централизованные экспорты из `@/components/icons`

### 6. **Тестирование гибридной архитектуры (✅ Завершено)**

## 🔧 **Технические детали**

### **Текущая структура проекта**
```
src/
├── components/          # Все компоненты в одной папке
│   ├── icons/          # Иконки
│   ├── files/          # Компоненты для работы с файлами
│   ├── collections/    # Компоненты для коллекций
│   ├── constructor/    # Компоненты конструктора парсеров
│   └── ...
├── lib/                # Утилиты и сервисы
├── types/              # TypeScript типы
├── config/             # Конфигурационные файлы
└── App.svelte          # Главный компонент
```

### **Path mapping алиасы**
- `@/*` - корень src
- `@/lib/*` - утилиты
- `@/components/*` - компоненты
- `@/types/*` - типы
- `@/config/*` - конфигурация

### **Система конфигурации**
- Компоненты можно включать/выключать
- Настройки сохраняются в localStorage
- Поддержка импорта/экспорта конфигурации
- Валидация и обработка ошибок
