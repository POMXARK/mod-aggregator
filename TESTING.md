## 🧪 Способы тестирования

### 1. Тестирование через Tauri Dev Mode (рекомендуется)

```bash
npm run tauri:dev
```

После запуска:
1. Откройте DevTools (F12)
2. В консоли выполните команды из `test-file-commands.js`
3. Или используйте UI для создания файлов через форму

### 2. Тестирование через браузер (Mock)

```bash
npm run dev
```

Mock-реализации добавлены в `src/lib/tauri-mock.ts` для всех команд файлов.

### 3. Ручное тестирование команд

#### Создание файла:
```javascript
const file = await invoke('create_file', {
  params: {
    name: 'my-mod',
    version: '1.0.0',
    path: '/path/to/mod',
    metadata: { author: 'Author', description: 'Description' }
  }
});
```

#### Создание файла с зависимостями:
```javascript
const file = await invoke('create_file', {
  params: {
    name: 'dependent-mod',
    version: '1.0.0',
    dependencies: [{
      target_file_name: 'my-mod',
      target_file_version: '1.0.0',
      dependency_type: 'required'
    }]
  }
});
```

#### Обновление файла:
```javascript
const updated = await invoke('update_file', {
  params: {
    id: file.id,
    path: '/new/path',
    metadata: { updated: true }
  }
});
```

#### Удаление файла:
```javascript
// Без force (проверка зависимостей)
const result = await invoke('delete_file', {
  file_id: file.id,
  force: false
});

// С force (принудительное удаление)
const result = await invoke('delete_file', {
  file_id: file.id,
  force: true
});
```

## 📝 Примеры тестовых сценариев

### Сценарий 1: Создание и обновление файла
1. Создайте файл `test-mod@1.0.0`
2. Обновите путь файла
3. Обновите метаданные
4. Проверьте, что изменения сохранились

### Сценарий 2: Работа с зависимостями
1. Создайте файл `base-mod@1.0.0`
2. Создайте файл `dependent-mod@1.0.0` с зависимостью от `base-mod`
3. Попытайтесь удалить `base-mod` без force - должна быть ошибка
4. Удалите `base-mod` с force - должно удалиться

### Сценарий 3: Версионирование
1. Создайте файл `my-mod@1.0.0`
2. Загрузите новую версию `my-mod@2.0.0`
3. Получите все версии `my-mod` - должно быть 2 версии
4. Проверьте, что обе версии существуют независимо

## User Story 3: File Import and Export

См. `TESTING-IMPORT-EXPORT.md` для подробной инструкции по тестированию импорта/экспорта.

**Быстрый тест:**
```bash
npm run tauri:dev
# В DevTools консоли:
const { invoke } = window.__TAURI__.core;
await testImportExport();
```

**Основные команды:**
- `export_file(file_id)` - экспорт файла в JSON
- `import_file(json_data)` - импорт файла из JSON
- `validate_import_json(json_data)` - валидация JSON перед импортом
