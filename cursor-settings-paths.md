# Пути поиска настройки Agent Skills в Cursor 2.3.18

## Основной путь (из документации):
1. Открыть настройки: `Ctrl+Shift+J`
2. Перейти в раздел **Rules**
3. Найти подраздел **Import Settings**
4. Включить **Agent Skills**

## Альтернативные пути поиска:

### Вариант 1: Раздел AI/Assistant
1. Cursor Settings → AI
2. Найти "Agent Skills" или "Skills"
3. Или проверить подраздел "Assistant Settings"

### Вариант 2: Раздел Features/Experimental
1. Cursor Settings → Features
2. Найти "Experimental Features" или "Beta Features"
3. Проверить "Agent Skills"

### Вариант 3: Поиск по названию
1. В строке поиска настроек ввести: "agent skills"
2. Или "skills"
3. Или "import"

### Вариант 4: Раздел Rules (расширенный поиск)
1. Cursor Settings → Rules
2. Проверить все подразделы:
   - Import Settings
   - AI Rules
   - Custom Rules
   - All Rules

## Если настройка не найдена:

### Возможные причины:
1. **Версия**: Возможно нужна более новая версия (Nightly)
2. **Регион**: Некоторые функции доступны не во всех регионах
3. **Тип аккаунта**: Некоторые функции требуют определенного типа аккаунта

### Действия:
1. Проверьте версию Cursor в Help → About
2. Попробуйте перезапустить Cursor
3. Проверьте наличие обновлений
4. Попробуйте другой канал обновлений (если доступно)

## Тестирование работы навыков

Даже без настройки в интерфейсе, навыки могут работать автоматически.
Для тестирования:

1. Создайте новый Svelte компонент с ошибками
2. Попробуйте получить помощь от AI ассистента
3. Проверьте, использует ли он ваш навык static-analysis-frontend-skill.md

## Резервный вариант

Если настройка недоступна, вы можете:
1. Использовать навыки через прямые команды
2. Создать скрипт автоматизации на основе вашего навыка
3. Интегрировать навык в процесс разработки вручную
