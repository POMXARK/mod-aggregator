# SpecKit - Spec-Driven Development

SpecKit установлен и готов к использованию! Этот инструмент помогает структурировать разработку через спецификации.

## Структура

```
mod-aggregator/
├── specs/                  # Спецификации для новых фич
│   └── 001-feature-name/   # Каждая фича в отдельной директории
│       ├── spec.md         # Спецификация
│       ├── plan.md         # План реализации
│       ├── tasks.md        # Разбивка на задачи
│       └── research.md     # Исследования (опционально)
├── memory/                 # Конституция и контекст проекта
│   └── constitution.md     # Основные принципы проекта
├── templates/              # Шаблоны для создания спецификаций
│   ├── spec-template.md
│   ├── plan-template.md
│   ├── tasks-template.md
│   └── CLAUDE-template.md
└── scripts/                # Вспомогательные скрипты
    ├── check-prerequisites.sh
    └── check-prerequisites.ps1
```

## Как использовать SpecKit

### Шаг 1: Создать спецификацию

1. Создайте новую директорию в `specs/`:
   ```bash
   mkdir specs/001-feature-name
   ```

2. Скопируйте шаблон спецификации:
   ```bash
   cp templates/spec-template.md specs/001-feature-name/spec.md
   ```

3. Заполните спецификацию, описав:
   - Пользовательские истории
   - Технические требования
   - Ограничения и зависимости

### Шаг 2: Создать план реализации

Используйте команду `/speckit.plan` в Claude Code с промптом:
```
Прочитай спецификацию в specs/001-feature-name/spec.md и создай 
детальный план реализации. Учти технический стек проекта (Tauri + Svelte 5).
```

Или создайте вручную, скопировав `templates/plan-template.md`.

### Шаг 3: Разбить на задачи

Используйте команду `/speckit.tasks` в Claude Code:
```
Разбей план из specs/001-feature-name/plan.md на конкретные задачи 
с учетом зависимостей и возможностей параллельного выполнения.
```

Или создайте вручную, скопировав `templates/tasks-template.md`.

### Шаг 4: Реализация

Используйте команду `/speckit.implement` в Claude Code:
```
Выполни задачи из specs/001-feature-name/tasks.md по порядку, 
следуя плану реализации и конституции проекта.
```

## Команды для Claude Code

- `/speckit.plan` - создать план реализации из спецификации
- `/speckit.tasks` - разбить план на конкретные задачи
- `/speckit.implement` - выполнить задачи по порядку

## Проверка предварительных требований

Перед началом работы проверьте, что все установлено:

**Windows (PowerShell):**
```powershell
.\scripts\check-prerequisites.ps1
```

**Linux/Mac:**
```bash
chmod +x scripts/check-prerequisites.sh
./scripts/check-prerequisites.sh
```

## Примеры использования

### Пример 1: Добавление нового парсера

1. Создайте `specs/002-synthira-parser/spec.md`
2. Опишите требования к парсеру
3. Используйте `/speckit.plan` для создания плана
4. Используйте `/speckit.tasks` для разбивки на задачи
5. Используйте `/speckit.implement` для реализации

### Пример 2: Новая фича UI

1. Создайте `specs/003-notifications-panel/spec.md`
2. Опишите компонент и его функциональность
3. Следуйте тем же шагам для планирования и реализации

## Дополнительные ресурсы

- Конституция проекта: `memory/constitution.md`
- Контекст для AI: `CLAUDE.md`
- Правила разработки: `.cursor/rules/`

## Советы

1. **Начинайте с малого**: Для простых фич можно пропустить некоторые шаги
2. **Используйте шаблоны**: Они помогут структурировать мысли
3. **Обновляйте конституцию**: Если правила меняются, обновите `memory/constitution.md`
4. **Документируйте решения**: Добавляйте `research.md` для сложных технических решений
