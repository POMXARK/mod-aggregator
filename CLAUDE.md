# Контекст для Claude Code: Mod Aggregator

Этот файл содержит контекст проекта для работы с Claude Code и другими AI агентами.

## Технический стек

### Frontend
- Svelte 5 с TypeScript
- Tailwind CSS
- @xyflow/svelte для графов
- Tauri API для взаимодействия с backend

### Backend
- Rust + Tauri 2.0
- SQLite через SQLx
- scraper для парсинга HTML
- reqwest для HTTP запросов

## Ключевые компоненты

### Frontend
- **ParserBuilder.svelte**: Визуальный конструктор парсеров с нодами
- **PageViewer.svelte**: Просмотр и сохранение веб-страниц
- **ModsList.svelte**: Список модов с карточками
- **SitesManager.svelte**: Управление сайтами

### Backend
- **database.rs**: Работа с SQLite
- **parser.rs**: Движок парсинга HTML
- **models.rs**: Модели данных (Site, Mod, Notification)

## Модели данных

### Site
- `id`, `name`, `url`, `parser_config`, `created_at`, `updated_at`

### Mod
- `id`, `site_id`, `title`, `url`, `version`, `author`, `description`, `image_url`, `changes`

## Специализированные навыки (Skills)

Проект использует **Claude Code Skills** для автоматизации специализированных задач разработки. Навыки автоматически активируются на основе семантического анализа запросов пользователя.

### Архитектура навыков:
- **Расположение**: `.claude/skills/[skill-name]/SKILL.md`
- **Формат**: YAML frontmatter + Markdown инструкции
- **Активация**: Автоматическая по ключевым словам в описании
- **Совместимость**: Claude Code, Cursor (Nightly канал)

### Доступные навыки:

#### 🎯 **resize-handle-component** (v1.0.0)
**Описание**: Создание переиспользуемых компонентов ResizeHandle для изменения размеров панелей в Svelte 5 приложениях.

**Когда использовать**:
- Добавление функциональности изменения размеров панелей
- Создание разделителей между областями интерфейса
- Реализация resizable layouts в Svelte 5

#### 💾 **state-persistence-svelte5-rust** (v1.0.0)
**Описание**: Реализация системы сохранения и восстановления состояния в приложениях с Svelte 5 frontend и Rust backend.

**Когда использовать**:
- Работа с состоянием UI между сессиями
- Сохранение пользовательских настроек
- Восстановление состояния приложения при запуске

#### 🔍 **static-analysis-frontend** (v1.0.0)
**Описание**: Проведение статического анализа Svelte 5 проектов с использованием svelte-check.

**Когда использовать**:
- Проверка качества кода Svelte 5
- Выявление ошибок типизации
- Обеспечение соответствия best practices

#### ⚠️ **static-analysis-frontend-warnings** (v1.0.0)
**Описание**: Управление предупреждениями и hints в svelte-check для оптимизации CI/CD логов.

**Когда использовать**:
- Настройка фильтрации предупреждений в CI
- Работа с проектами с legacy кодом
- Оптимизация вывода статического анализа

#### 🧪 **test-skill** (v1.0.0)
**Описание**: Тестовый навык для проверки работы системы навыков Claude Code.

**Когда использовать**:
- Тестирование загрузки и активации навыков
- Проверка выполнения Python команд
- Валидация работы системы навыков

#### 📚 **skill-creation-guide** (v1.0.0)
**Описание**: Руководство по созданию навыков Claude Code. Использовать когда нужно создать новый навык, улучшить существующий или изучить best practices создания навыков.

**Когда использовать**:
- Создание новых навыков
- Изучение структуры SKILL.md файлов
- Получение шаблонов и примеров
- Валидация созданных навыков

### Как работают навыки:

1. **Загрузка**: При запуске системы сканирует `.claude/skills/`
2. **Активация**: Анализирует запросы на соответствие описаниям навыков
3. **БЛОКИРОВКА**: Правило `skill-confirmation` запрещает автоматическое выполнение
4. **ПОДТВЕРЖДЕНИЕ**: Требует явного согласия пользователя
5. **Исполнение**: Только после подтверждения следует инструкциям из SKILL.md

### Подтверждение использования навыков:

В **Cursor IDE** применяется специальное правило `skill-confirmation.mdc`, которое:

- **Запрашивает подтверждение** перед применением любого навыка
- **Показывает информацию** о навыке (название, описание, действия)
- **Позволяет выбрать**: применить навык или продолжить без него
- **Обеспечивает контроль** над автоматизированными действиями

**Расположение правила:** `.cursor/rules/skill-confirmation.mdc`

### Проверка работы:

**В Claude Code:**
```bash
# Проверить доступные навыки
What Skills are available?

# Протестировать активацию навыков
Создай компонент изменения размеров в Svelte 5
Реализуй сохранение состояния в Svelte 5 + Rust
Проведи статический анализ Svelte проекта
Настрой управление предупреждениями svelte-check

# Тестирование системы навыков
Протестируй работу навыков
Проверь систему навыков

# Создание навыков
Создай новый навык для [задачи]
Как создать навык Claude Code
Нужен шаблон для SKILL.md
```

**В Cursor (Nightly):**
- ⚠️ **АВТОМАТИЧЕСКОЕ ВЫПОЛНЕНИЕ ЗАПРЕЩЕНО!**
- Правило `skill-confirmation` блокирует автоматическое применение навыков
- 🔴 **ОБЯЗАТЕЛЬНО** показывает информацию о навыке и запрашивает подтверждение
- ✅ Только после явного согласия пользователя выполняется автоматизация

### Настройка подтверждения навыков в Cursor:

1. **Включить правило:**
   - Открыть **Cursor Settings → Rules**
   - Найти **skill-confirmation**
   - Установить режим: **ask** (запрашивать подтверждение)

2. **Тестирование:**
   - Написать запрос, подходящий под навык
   - Проверить появление диалога подтверждения
   - Протестировать оба варианта (принять/отклонить)

3. **Исключения:**
   - `skill-creation-guide` - информационный навык
   - `test-skill` - для проверки работоспособности
