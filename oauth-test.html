Тест подключения к localhost для OAuth

Это поможет определить, может ли браузер подключаться к локальному приложению.

Если тест не прошел:

  • Измените DNS настройки в Mullvad Browser с "Max Protection" на "Standard"
  • Используйте обычный Chrome для OAuth авторизации
  • Отключите DNS over HTTPS временно
  • Попробуйте заменить localhost на 127.0.0.1 в URL
