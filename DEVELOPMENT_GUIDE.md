# 🎯 Руководство по разработке - Отключение компонентов

## Как отключать компоненты для фокусированной разработки

### 🚀 Быстрый старт

1. **Откройте приложение**: `npm run dev`
2. **Перейдите в "Настройки"** в боковом меню
3. **Выберите режим разработки**:
   - 🔧 **Только Parser** - для разработки парсера
   - 🌐 **Только Sites** - для управления сайтами
   - 📁 **Только Files** - для работы с файлами
   - ✅ **Все компоненты** - полное приложение

### 🎛️ Способы управления компонентами

#### 1. Через UI (рекомендуется)
- Откройте страницу "Настройки"
- Используйте кнопки профилей для быстрого переключения
- Или настройте компоненты индивидуально

#### 2. Через браузерную консоль
```javascript
// Импортируйте helpers
import('./config/development-helpers.js').then(m => {
  // Переключитесь на режим только Parser
  m.enableParserOnly();

  // Или только Sites
  m.enableSitesOnly();

  // Или включите все
  m.enableAllComponents();

  // Проверьте текущие настройки
  m.getCurrentConfig();
});
```

#### 3. Программно в коде
```typescript
import { applyDevelopmentProfile, resetToFullConfig } from '@/config/components';

// Применить профиль Parser
applyDevelopmentProfile('parserOnly');

// Вернуться к полной конфигурации
resetToFullConfig();
```

### 📋 Доступные профили разработки

| Профиль | Что включено | Для чего |
|---------|---------------|----------|
| `parserOnly` | Parser + Sidebar | Разработка конструктора парсеров |
| `sitesOnly` | Sites + Sidebar | Управление сайтами |
| `filesOnly` | Files + Collections + Sidebar | Работа с файлами и коллекциями |

### 🔧 Настройка собственных профилей

Добавьте новый профиль в `src/config/components.ts`:

```typescript
export const developmentProfiles = {
  // Существующие профили...

  // Ваш новый профиль
  myCustomProfile: {
    mods: { enabled: false, priority: 1 },
    sites: { enabled: true, priority: 2 },
    parser: { enabled: false, priority: 3 },
    files: { enabled: true, priority: 4 },
    collections: { enabled: false, priority: 5 },
    notifications: { enabled: false, priority: 6 },
    aiChat: { enabled: false, priority: 7 },
    sidebar: { enabled: true, priority: 8 }
  }
};
```

### 💾 Сохранение настроек

- **Автоматически**: настройки сохраняются в `localStorage`
- **Экспорт**: через UI настроек можно экспортировать конфигурацию в JSON
- **Импорт**: можно загрузить сохраненную конфигурацию

### 🔄 Перезагрузка после изменений

После изменения профиля **перезагрузите страницу** для применения изменений.

### 🎯 Примеры использования

#### Разработка Parser компонента:
1. Выберите "🔧 Только Parser"
2. Перезагрузите страницу
3. Видите только Parser + базовую навигацию
4. Фокусируйтесь на разработке парсера без отвлечений

#### Тестирование полного приложения:
1. Выберите "✅ Все компоненты"
2. Перезагрузите страницу
3. Все компоненты включены для полной проверки

### 🚨 Важные замечания

- **Все компоненты включены**: Parser, Sites, Files и другие компоненты теперь полностью функциональны.
- **Tauri зависимости**: компоненты, использующие Tauri API, работают только в `npm run tauri:dev` режиме.
- **Кеш Vite**: после изменений очищайте кеш если возникают проблемы с импортами.

### 🐛 Проблемы и решения

#### Ошибки импорта
```bash
# Очистите кеш Vite
rm -rf node_modules/.vite
npm run dev
```

#### Компонент не включается
- Проверьте настройки в localStorage: `localStorage.getItem('components-config')`
- Сбросьте настройки: в консоли `import('./config/development-helpers.js').then(m => m.resetEverything())`

### 📞 Поддержка

Если возникли проблемы:
1. Проверьте консоль браузера на ошибки
2. Попробуйте сбросить настройки
3. Очистите кеш Vite
4. Перезапустите приложение

---

*Эта система позволяет эффективно разрабатывать отдельные части приложения без отвлечений на другие компоненты.*
