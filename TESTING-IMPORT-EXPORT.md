# Тестирование импорта/экспорта файлов

## Быстрый старт

### Вариант 1: Тестирование через Tauri Dev Mode (рекомендуется)

1. Запустите приложение:
```bash
npm run tauri:dev
```

2. Откройте DevTools (F12 или Ctrl+Shift+I)

3. В консоли выполните:
```javascript
// Импортируем invoke
const { invoke } = window.__TAURI__.core;

// Запускаем тесты
await testImportExport();
```

### Вариант 2: Тестирование через браузер (Mock)

1. Запустите dev сервер:
```bash
npm run dev
```

2. Откройте консоль браузера

3. Выполните команды из `test-import-export.js` вручную

## Ручное тестирование команд

### 1. Экспорт файла

```javascript
// Сначала создайте файл
const file = await invoke('create_file', {
  params: {
    name: 'my-mod',
    version: '1.0.0',
    path: '/path/to/mod',
    metadata: { author: 'Author Name' }
  }
});

// Экспортируйте файл
const json = await invoke('export_file', {
  file_id: file.id
});

console.log('Экспортированный JSON:', json);
```

### 2. Валидация JSON перед импортом

```javascript
const validation = await invoke('validate_import_json', {
  json_data: json
});

console.log('Валиден:', validation.valid);
console.log('Ошибки:', validation.errors);
console.log('Предупреждения:', validation.warnings);
```

### 3. Импорт файла

```javascript
const result = await invoke('import_file', {
  json_data: json
});

console.log('Файл создан:', result.created);
console.log('ID файла:', result.file_id);
console.log('Отсутствующие зависимости:', result.missing_dependencies);
```

## Тестирование через UI

### Экспорт через ExportDialog

1. Откройте приложение: `npm run tauri:dev`
2. Создайте или выберите файл
3. Откройте диалог экспорта (через UI или программно)
4. Нажмите "Экспортировать"
5. Проверьте, что файл скачался

### Импорт через ImportDialog

1. Откройте диалог импорта
2. Выберите JSON файл или вставьте JSON вручную
3. Нажмите "Проверить JSON" для валидации
4. Если валидация прошла, нажмите "Импортировать"
5. Проверьте результат импорта

## Примеры тестовых сценариев

### Сценарий 1: Экспорт и импорт файла
1. Создайте файл `test-mod@1.0.0` с зависимостью
2. Экспортируйте файл
3. Удалите файл
4. Импортируйте файл из экспортированного JSON
5. Проверьте, что файл восстановлен со всеми параметрами

### Сценарий 2: Обновление через импорт
1. Создайте файл `my-mod@1.0.0`
2. Экспортируйте файл
3. Измените метаданные в JSON
4. Импортируйте измененный JSON
5. Проверьте, что файл обновлен

### Сценарий 3: Импорт с отсутствующими зависимостями
1. Экспортируйте файл с зависимостью от `base-mod@1.0.0`
2. Удалите `base-mod@1.0.0`
3. Импортируйте файл
4. Проверьте, что файл создан, но зависимость отмечена как отсутствующая
